6. Үлдсэн алхам хийх шаардлагатай

  1. Service account key авх — Expo-ийн заавар. Google Cloud → IAM & Admin → Service Accounts → шинэ account → Manage keys → Create new key → JSON. Файлыг tuvshuu/play-service-account.json гэж нэг репозитороос гадуур хадгална (.gitignore дотор байгаа). Play Console → Users and permissions → энэ email-ийг invite хийж: View app information, Edit and delete draft apps, Release to production, Release apps to testing tracks, Manage testing tracks, Manage store presence эрхүүдийг өгнө.
  2. Phone screenshots — апп ажиллаж байгаа учраас бодит дүрсийг өөрийн төхөөрөмжөөс авна уу. 2-оос багагүй, 16:9 эсвэл 9:16 харьцаатай, 320–3840px урт. Зар сэтгэл хөдөлгөөнтэй худалдааны үйлдэл харагдах дүрсүүд хамгийн тохиромжтой.
  3. Store listing хэсгүүдийг дүүргэх — дээрх бэлэнлээс шууд paste хий.
  4. Data safety хэсгийг дүүргэх — дээрх хүснэгтээр.
  5. Content rating — бүгд None гэж тэмдэглэ.
  6. Internal testing оронд оруулах — cd warehouse-mobile && npx eas-cli submit --platform android --profile production --latest
  7. Internal testing → Closed testing → Production — алхам алхмаар, дор хаяж 14 хоног closed testing дээр байх шаардлагатай.

Нэг зүйл анхаарч байна: AAB билдүүлэлт амжилттай болсон ч бодит төхөөрөмж дээр апп ажиллаж үзээгүй. Интернэтийн холбоо, бүртгэл, е-баримт үүсгэх, хэвлэх гэсэн урсгалыг device дээр шалгаад production-д илгээх нь зөв. Энэ нь урьдчилан төлөвлөөд Internal testing-ээр турших боломжтой.
